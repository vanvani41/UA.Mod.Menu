<summary><b>English</b></summary>

UA Mod Menu is a **first ukrainian** mod menu for Gorilla Tag, made by me, [**vanvani41**](https://github.com/vanvani41). Right now there's no ukrainian language in the menu, but in the future, i think i will add it. Also, i used [iis Stupid Template](https://github.com/iiDk-the-actual/iis.Stupid.Template) and Claude Sonnet 4.5 Adaptive for fixes and some kind of mods to make UA Mod Menu.

<details>
<summary><b>Why menu is open-source?</b></summary>

I want to help other guys to create a mod menu too! I want to share the code of UA Mod Menu, so you can learn how to create their **own** mod menu too.
And i am going to make a tutorial, to help **YOU** create your own mod menu, but it will be later. + There will be mods from UA Mod Menu.

<summary><b>How to install the mod menu?</b></summary>

<details>
<summary><b>If you **don't have** BepInEx</b></summary>

1. Download the latest release of MonkeModManager [**right here**](https://github.com/BzzzThe18th/MonkeModManager/releases/latest)
2. Open MonkeModManager and click "Install / Update"
2.1 If you got an error, it means that MonkeModManager can't find your Gorilla Tag folder, so you need find Gorilla Tag.exe file (It is usually happen with Oculus version).
</details>

<details>
<summary><b>If you **have** BepInEx</b></summary>

1. **Download** the latest release **[right here](https://github.com/vanvani41/UA.Mod.Menu/releases/latest)**
2. **Save** `UA.Mod.Menu.dll` into your Gorilla Tag/BepInEx/plugins folder  
3. **Launch Gorilla Tag and enjoy!**
</details>

<summary><b>Як встановити мод меню?</b></summary>

<details>
<summary><b>Якщо ви **не маєте** BepInEx</b></summary>

1. Завантажте останній реліз [**ось тут**](https://github.com/BzzzThe18th/MonkeModManager/releases/latest)
2. Відкрийте MonkeModManager та нажміть на "Install / Update"
2.1 Якщо ви отримали помилку, це означає, що MonkeModManager не може знайти вашу папку Gorilla Tag, тому вам потрібно знайти файл Gorilla Tag.exe (це зазвичай трапляється з версією Oculus).
</details>

<details>
<summary><b>Якщо ви **маєте** BepInEx</b></summary>

1. **Завантажте** останній реліз [**ось тут**](https://github.com/vanvani41/UA.Mod.Menu/releases/latest)
2. **Збережіть** `UA.Mod.Menu.dll` у папку Gorilla Tag/BepInEx/plugins
3. **Запускайте** Gorilla Tag та грайте!
</details>
